# Taller Android — Herramientas financieras

Aplicación desarrollada en Java con Android Studio.

- Convertidor entre COP, USD, EUR y MXN, con tasas de referencia incluidas en la aplicación.
- Calculadora de crédito con cuota mensual fija, total a pagar e intereses.
- Navegación entre pantallas y validación de datos.

El código está en `app/src/main`.
